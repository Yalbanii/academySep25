Resumen del proyecto:

  Tecnologías:
  - Spring Boot 3.5.6
  - Spring Modulith 1.4.1
  - Java 21
  - MySQL
  - JPA/Hibernate
  - Lombok
  - SpringDoc OpenAPI

  Arquitectura modular:
  - allocation - Gestión de espacios de estacionamiento
  - billing - Sistema de facturación
  - entry - Control de entrada/salida de vehículos
  - event - Eventos del sistema (entrada/salida)
  - notification - Servicio de notificaciones

  Funcionalidades principales:
  - API REST para entrada/salida de vehículos (/parking/entry, /parking/exit)
  - Gestión automática de espacios disponibles
  - Sistema de eventos para comunicación entre módulos
  - Base de datos MySQL configurada
  - Documentación API con OpenAPI/Swagger
  - Puerto: 9191

  El proyecto sigue principios de Spring Modulith para una arquitectura modular bien
  estructurada, con separación clara de responsabilidades entre los diferentes módulos del sistema.
